# Hi, I'm north30 👋

I got tired of uploading photos to random websites just to make them smaller,
so I built the thing I wanted to exist.

🌐 **[imagetoolforge.com](https://imagetoolforge.com)** — compress images to an exact
target size (100KB, 200KB, whatever the form demands), convert formats, strip
EXIF, resize in batch. Everything runs in your browser via WebAssembly. Your
files never touch a server, because there isn't one.

The part I'm most proud of: instead of a quality slider you drag and pray,
you type the size you need and a binary search finds the best quality that
actually fits. It either hits the number or tells you honestly that it can't.
